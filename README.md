# Zen App · 人间净土修学原型

本仓库保存导师指派、学员修学与个人历程的手机 H5 原型，以及菩提导航等应用的产品调研结论和分析脚本。

## 打开原型

原型为静态 HTML、CSS、JavaScript，无后端或构建依赖。下载仓库后，可用电脑浏览器直接打开 `prototype/index.html`。

如需通过本地网址预览，在仓库目录运行：

```sh
python3 -m http.server 4176 --bind 127.0.0.1 --directory prototype
```

随后打开 `http://127.0.0.1:4176/`。页面左侧可切换学员端和法师端。

当前原型规则（24门课程版）：

- 依据《五正课程设计初稿》：正人8门、正信7门、正愿2门、正行7门，公共导读单独保留。
- 首页五瓣莲花直接进入对应类别详情，正见汇总已开放理论，四个行门展示对应课程；青瓷背景下方的宣纸续学区显示上次实际阅读或反思的位置，底部采用宣纸文字页签。目录、占位页和返回操作不覆盖它；课程文章恢复上次小节与滚动位置。
- 法师安排完整课程并填写指导与要求；固定行门配套在课程设计阶段确认，日常不逐张勾选。
- 闻为讲解资料，思为自检、心得与问题，修为适用实践。无独立实践不强加。
- 配套待法师确认的内容明确标注，不编造资料、题目、分数或完成标准。当前可演示安排与保存心得，不能提交或确认结课。
- “我的”、历程及预览导航保留独立“自修自检”入口，支持随时记录个人自检心得、自选主题与睡前／自定时间／不固定的定课设置；旧daily地址直接进入自修自检，旧设置继续使用。个人记录仅保存在本机，可在历程回看，不替代专项表单、回向或课程要求。各课程“思”中的专项自检及待确认说明继续保留。
- 新增个人TXT阅读器、由实际阅读／反思触发的自动计时和念佛计数。缺失的课程教材与配套继续标注，个人工具记录不判定结课。
- 闻页开始学习可直接阅读一篇标注为原型演示的3节样稿，支持自动计时；底部固定提供目录、书签与阅读设置。样稿与个人TXT共用字体、字号、行距和背景偏好，设置即时生效并本地保存；演示时长另列，正式教材仍待接入。
- 文章末节可直接写本课心得或记录问题，返回文章时恢复阅读位置；该入口可选，不把闻思修变成强制闯关。
- 课程内去掉独立计时入口，占位页不计时；修的开始修习待配套确认后启用，手动个人计时统一从我的→阅读与修学工具进入。
- 阅读与反思只显示本次时长，离开实际内容时自动记录；反思内容在本机自动暂存，保存并返回一并收尾，内容未变化不重复生成心得事件。阅读面板或切后台时暂停，返回实际内容后继续。个人手动计时仍保留结束确认、时长修正和选填心得；旧确认草稿保留。历程按结束日期统计每日次数、总时长及闻思修分项，暂不做番茄钟循环。
- 首页原消息铃铛展示未读提醒；列表只来自当前学员实际已有的法师安排、指导和明确回复，点击查看对应反馈或课程。阅读状态本地保存，新指导重新提醒；普通指导更新不冒充问题答复。
- 底部为修学、历程、我的；历程默认展示已完成、正在修学、后续安排三段个人路线，每门课一个节点，点击查看课程进展。与当前学员真实最近学习位置对应的节点标注“上次学习”，不另放继续学习卡片。已完成仅取法师确认的课程，默认最近2门；正在修学展示全部当前已安排／已提交课程；后续仅取法师显式安排，暂无则显示待法师安排，不补入其余课程。
- 课程进展二级页展示实际指导、已保存心得及关联工具记录、闻思修内容缺口；已完成与后续安排只读，不自动开放内容。历程底部保留详细学习记录入口，工具仍从我的进入；自修自检可独立进入；周计划与周回顾入口收起，旧存储保留。

人物、日期与安排为演示数据。操作记录保存在当前浏览器，不跨设备同步，也不保存在 Git 仓库中。

```sh
node --check prototype/app.js
node prototype/qa/check-unit-model.cjs
node prototype/qa/check-study-tools.cjs
node prototype/qa/check-study-notices.cjs
```

## 重置电脑后恢复

```sh
git clone https://github.com/leovince57/Zen_App.git
cd Zen_App
```

打开 `prototype/index.html` 即可继续预览和修改。分析报告及配置可直接查看；继续操作手机或运行 REA 分析时，需要另行安装 ADB、REA、JDK 等工具，并重新建立登录态。工具版本记录见 `research/reverse-analysis/environment.json`。

## 上传范围与备份界限

本仓库是可公开的项目源码与调研文档备份，不是整个本机工作目录的完整归档。

- 原始手机截图、UI 转储、抓包及反编译证据、设备运行状态可能包含账号或环境信息，保留在本地，不上传公开仓库。报告中的相关证据链接在远端可能不可用。
- 原应用 APK、调研副本 APK、签名材料、缓存、Python 虚拟环境和本机 REA 工具目录不上传。
- 原导图 PDF 与最初的简版功能文档不在当前项目目录中；导图的已核对结构保存在课程目录与对照文档中。
- 浏览器里的演示记录、账号密码、SSH 密钥和本机聊天记录不随本仓库恢复。

如需保留上述本地材料，请在抹掉电脑前另行备份到自己的外置储存设备。不要把 GitHub 上传成功视为整机备份完成。

首页下半屏使用延续到底部导航的连续宣纸底面，移除独立纸卡的外露边缘、阴影和纸下间隔。“继续学习”与“自修自检”统一为20px宋体标题；首页入口标题20px，环节与自检说明13px，箭头统一为22px且操作区至少44px。两项间用一条细线分隔，统一26px左右边距。保留348px莲花及动效，移除之前的负margin补偿，按实际内容自然排布；长内容可滚动。自修自检从首页进入后返回首页，刷新与定课子页保留来源。我的、历程及课程“思”中的专项自检继续保留。

首页两个操作行统一为相同的两行结构：20px宋体标题，13px说明；续学说明包含课程名和当前环节。两行共用108px最小高度、24px上下内边距和44px箭头容器，箭头中心与文字组中心一致。
