# 人间净土手机H5原型：24门课程版

依据[source/五正课程设计初稿.md](source/五正课程设计初稿.md)调整。正人8门、正信7门、正愿2门、正行7门；公共导读独立保留。

从仓库根目录启动：

```sh
python3 -m http.server 4176 --bind 127.0.0.1 --directory prototype
```

打开 http://127.0.0.1:4176/ 。也可以直接用电脑浏览器打开index.html。

## 体验入口

首页采用哑光青瓷、立体暖白莲花和自然白宣纸续学区；“觉”保留哑光金铜与边缘薄片磨损。底部为宋体文字页签，选中项用深青字色、字重和短细线标识；导航与安全区延续宣纸。解行说明集中在“觉”弹窗。

- 首页莲花：使用已确认的侧面轻盈五瓣；点击后轻轻舒展、回落再进入类别详情，快速连点不重启动画。减少动态效果时直接跳转；“觉”打开五正修学说明。四个行门展示对应课程，已安排优先、未安排锁定；正见只汇总已开放课程理论。
- 继续上次学习：首页莲花下方保留简洁入口，仅显示课程、上次停留环节与继续箭头。只把实际文章阅读或反思作为续学位置，目录、占位页和返回动作不覆盖；课程文章按各课保存小节与滚动位置，刷新或返回后可恢复。无实际学习记录时显示开始学习，不标为“上次学习”。
- 首页不再保留重复课程目录或下拉切换。公共导读、已安排课程与辅助工具从我的进入。
- 法师端→学员→安排课程：24门中选一门或多门，写指导及要求，发布演示安排。新增不覆盖原有课程，同一进行中课程不能重复安排。
- 首页消息铃铛保留原位置，显示当前学员的未读安排、指导或明确回复。列表只取实际已有记录，点击进入相关反馈与课程；已读状态本地保存，新更新重新成为未读。法师可针对学员保存的问题填写选填回复，普通指导更新不自动判定问题已回答。
- 课程内部：闻查看理论路径；思列专项自检并保存心得与问题；修列待确认的实践范围。
- 固定课程配置：初稿已明确对应与待法师确认的配套分开展示，不能在日常安排中自行配表或强加实践。
- 历程：默认是已完成、正在修学、后续安排三段个人路线，每门课程一个节点。点击节点进入课程进展二级页，查看实际指导、已保存心得与关联工具记录、闻思修缺口。底部保留详细学习记录入口，工具仍从我的进入。
- 自检统一从各门课程的“思”进入，只显示本课已明确关联的专项自检及待确认缺口；真实表单、必填规则、评分和完成要求未齐备时，不能填写、计分或生成自检完成记录。
- “我的自检定课”独立入口从我的、历程的持续修习链接、桌面侧栏和移动预览导航收起，暂不做每日自检。旧`daily`地址回到已安排课程，选择具体课程后从“思”进入自检；旧个人选择与时间偏好仅保留，不启用、不迁移为课程要求或学习记录。初稿中的各门定课自检仍保留待法师确认的配套归属，不因此默认开放。
- 公共导读及法师端原图行门目录保留。原39组导图转录不再作为66个独立可安排单元。

## 阅读、计时与计数

- 闻页的开始学习直接进入3节通用演示文章《把注意力带回当下》，含正文、目录、翻节、书签及自动计时；不用先导入文件。目录、书签和阅读设置各有固定底部入口。演示进度与时长标注演示，时长单列不混入正式累计，正式教材与配套仍待接入。
- 文章末节提供可选的写心得／记录问题入口，直接进入同一课程的反思；返回文章时恢复小节与位置，不强制完成闻思修顺序，也不以翻到末尾判定学完。
- 课程内不再有独立的计时入口。闻的教材占位页、思的待接入自检目录和修的未确认说明页都不计时。
- 阅读器导入真实个人TXT后，打开正文自动记个人闻时长；个人文件不视为课程教材。保留分页、位置与书签，只提供页码跳转，不虚构章节目录。
- 演示文章和个人TXT共用本地阅读偏好：宋体／黑体／楷体、16–28号字号、紧凑／标准／宽松行距，以及纸色／白色／护眼绿／夜间背景。字体使用设备系统字体并提供回退。选择即时生效、刷新后保留；恢复默认只重置阅读样式，不清除正文、位置或书签。
- 思目录与实际心得编辑页分开，点击开始／继续反思后自动计思时长；自检表未接入，不虚构题目或分数。
- 阅读正文上方只显示本次阅读时长，不提供计时按钮或计时详情入口。返回或切换页面离开阅读器时自动保存到历程，以“本次阅读…，已记录”轻提示反馈，不进入确认页；不足1秒的访问不生成零时长记录。
- 打开阅读设置、目录或书签面板，以及切到后台时自动暂停；回到正文后继续。翻页／翻节仍属于同一次阅读。刷新从已保存的计时位置恢复，刷新与关闭间隔不计入。旧版待确认计时草稿保留，不自动确认；其他未处理会话不被覆盖。
- 反思与阅读采用同样的自动计时：编辑页只展示本次时长，切后台暂停，返回编辑恢复，离开页面时自动记录实际时长，不再另做计时结束确认。心得与问题在本机自动暂存；保存并返回一并保存内容和时长，内容未变化不重复生成心得事件。
- 修保留开始修习，但当前课程配套未确认，暂不可开始。我的→阅读与修学工具→个人计时保留手动独立修习，按个人选择记录闻／思／修，不自动绑定课程。
- 个人手动计时的结束确认仍可校正时长、说明调整原因并选填心得，保留原值，不覆盖课程原心得。阅读与反思按实际时长自动记录，旧版已进入结束确认的草稿保留供继续处理，不自动确认或丢弃。
- 保存后可继续原环节或查看历程。学习记录可按日期筛选，显示当日总时长、次数、闻思修分项；按北京时间结束日期归档，旧记录缺少环节保留未标注。当天累计可展开；无日期或无具体时刻的分别说明，不补造时间。暂停和未保存时长不累计，不做番茄钟循环。
- 课程的修继续展示待法师确认的配套，提供独立个人念佛计数入口。支持点按、+10、撤销、补记与草稿恢复，没有默认目标。
- 我的→阅读与修学工具可直接使用这些工具。记录统一放在历程→查看学习记录，按阅读、计时、念佛、心得／指导筛选及回看详情。
- 课程结课门禁保留，实际教材、表单与完成要求齐备前不可提交或确认。个人工具使用不开放未安排课程。

## 未确认内容

真实教材、表单、自检评分、回向文本及完成规则仍待接入／确认。个人TXT试读、工具时长和次数不替代它们。正人8门、正愿2门、正行7门的未定配套，正信额外表单的开放范围，以及结课后长期使用权限等继续标注；不生成替代内容。当前安排、心得、阅读偏好及辅助工具可操作，提交与法师确认完成禁用。

当前人物、日期、指派与指导为演示。记录仅保存在本浏览器。v5使用renjian-study-prototype.v5-courses；不删除旧v4记录，不自动推定旧单元与新课程的对应。

## 离线交付

```sh
node prototype/scripts/build-offline.cjs
```

输出delivery/1.html，CSS、课程目录、study-tools.js、study-notices.js与app.js均内嵌。delivery/zen-preview.zip包含同版HTML与使用说明，解压后电脑浏览器打开即可。file模式采用hash路由，HTTP采用query路由。浏览器工具不允许file协议，本轮按源码和模型核验离线结构，未宣称通过工具直接打开file文件。

## 个人路线与课程进展

历程默认按已完成、正在修学、后续安排展示个人路线，每门课一个节点。三段说明个人实际安排与状态，不代表统一阶段、固定闯关次序或自动晋级。仅在真实 `lastStudy` 对应的当前学员课程节点标注“上次学习”，不另放重复卡片；无有效最近记录时不显示该标记，其他学员的记录不混入。

- 已完成：仅纳入 `status=completed`、语义为法师已确认完成的课程，默认显示最近2门，更多折叠。没有确认记录时如实显示空状态，不从阅读、时长、次数或心得推定完成。
- 正在修学：当前已安排与已提交课程都作为独立、同级节点展示，不因尚未开始阅读就归入后续安排，也不按课程目录顺序隐藏其他进行中课程。
- 后续安排：仅展示法师显式设置的 `status=planned` 课程。现有数据没有此类安排时显示“待法师安排”，不把24门中其余未安排课程补入路线，不编造未来要求；本次不增加法师排课表单。

点击课程节点进入 `course-progress` 二级页。页面展示当前实际保存的指导与要求、已保存心得和实际关联该课的工具记录，并逐项说明闻思修已接入内容及仍待确认的缺口。正在修学课程按已有权限继续学习或查看提交情况；已完成与后续安排只读，不能由此开放学习内容。工具时长、次数和演示阅读均不替代课程要求或法师确认。

历程底部保留详细学习记录入口，持续修习链接收起；自检回到具体课程的“思”，辅助工具仍从我的进入。周计划与周回顾页面入口移除，旧存储保留，不迁移成课程安排；原个人自检定课设置同样保留但不启用，暂不做每日自检。

## 详细学习记录

全部详细事件记录保留在二级入口，可按日期、类型及课程回看。只从发生事实形成事件：发布课程安排、进入实际阅读／反思、保存心得或工具记录、法师更新指导、法师实际确认课程完成。目录访问不记为学习；同日同课同内容的进入事件去重。已有阅读进入／计时的，阅读位置与书签并到详情，减少重复事件。

当前课程缺口仍然存在，不开放结课操作，也不为完成筛选填假记录。新安排保留原始指导快照，后续调整不改写原安排；旧记录不倒填缺失的精确时间或原始指导。学员与法师都可查看相应学员的个人路线、课程进展和详细记录；法师查看不改变课程内容权限。
