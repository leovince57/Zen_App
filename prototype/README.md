# 人间净土手机H5原型：24门课程版

依据[source/五正课程设计初稿.md](source/五正课程设计初稿.md)调整。正人8门、正信7门、正愿2门、正行7门；公共导读独立保留。

从仓库根目录启动：

```sh
python3 -m http.server 4176 --bind 127.0.0.1 --directory prototype
```

打开 http://127.0.0.1:4176/ 。也可以直接用电脑浏览器打开index.html。

## 体验入口

- 首页莲花：正见“解”汇总已开放课程理论；四个“行”瓣进入对应课程。未安排课程锁定。
- 法师端→学员→安排课程：24门中选一门或多门，写指导及要求，发布演示安排。新增不覆盖原有课程，同一进行中课程不能重复安排。
- 课程内部：闻查看理论路径；思列专项自检并保存心得与问题；修列待确认的实践范围。
- 固定课程配置：初稿已明确对应与待法师确认的配套分开展示，不能在日常安排中自行配表或强加实践。
- 历程：课程安排与学习记录合并，按实际安排时间展示，不设统一晋级阶段。
- 我的自检定课：只在已安排课程及初稿明确关联的自检中保存个人选择和时间偏好。真实表单未接入，不能填写、计分或生成回向记录。
- 公共导读及法师端原图行门目录保留。原39组导图转录不再作为66个独立可安排单元。

## 未确认内容

真实教材、表单、自检评分、回向文本及完成规则仍待接入／确认。正人8门、正愿2门、正行7门的未定配套，正信额外表单的开放范围，以及结课后长期使用权限等继续标注；不生成替代内容。当前安排、心得、个人设置可操作，提交与法师确认完成禁用。

当前人物、日期、指派与指导为演示。记录仅保存在本浏览器。v5使用renjian-study-prototype.v5-courses；不删除旧v4记录，不自动推定旧单元与新课程的对应。

## 数据和验证

curriculum.json与curriculum.js保持相同数据，courses为24门课程配置；sourceGroups保留原图转录。

```sh
node --check prototype/app.js
node prototype/qa/check-unit-model.cjs
```

验证包括24门数量、配套缺口、原目录保留、多课安排与隔离、自检权限、完成限制和离线hash路由。

## 离线交付

```sh
node prototype/scripts/build-offline.cjs
```

输出delivery/1.html，CSS与脚本内嵌。delivery/zen-preview.zip包含同版HTML与使用说明，解压后电脑浏览器打开即可。file模式采用hash路由，HTTP采用query路由。浏览器工具不允许file协议，本轮按源码和模型核验离线结构，未宣称通过工具直接打开file文件。
