# 五正课程设计（精简版）

## 1. 设计口径

- **导图定结构**：课程内容、原有层级、顺序和解行归属，以修学导图为准；原文解释含义，真机目录定位资料。
- **四类课程供法师安排**：正人课8门、正信课7门、正愿课2门、正行课7门，共24门；导读单独保留。这是本次讨论确定的软件安排方式，不是把原图改成四正或删除正见。
- **每门包含固定的“正见＋对应行门内容”**：先整理配套内容，请法师在课程设计阶段确认，确认后固定；日常安排时法师只选课程，不再逐个选资料、自检或实践。
- **因人而异、多课并行**：法师决定给谁开放哪一门或多门；新增课程不覆盖原安排。学员自行提交已学完，由法师评判和确认。
- **闻思修沿用现有口径**：闻＝讲解资料；思＝自检、心得与问题；修＝念佛、拜佛、诵念等实践。没有独立实践的课程不强行添加“修”。

## 2. 四类24门课程

```text
法师可安排的课程
├─ 正人课：8门（专修／选修 × 国家、儒家、道家、佛家）
├─ 正信课：7门
├─ 正愿课：2门
└─ 正行课：7门

每门课程
├─ 正见：固定的讲解资料
└─ 对应行门内容：固定的专项自检、诵念或其他实践
   └─ 具体配套先经法师确认，不由软件猜配
```

### 2.1 正人课：8门

| 课程 | 正见内容范围 | 对应正人内容 |
|---|---|---|
| 专修国家 | 正见 → 正人 → 专修 → 国家主流思想 | 待法师确认后固定 |
| 专修儒家 | 正见 → 正人 → 专修 → 儒家之见 | 待法师确认后固定 |
| 专修道家 | 正见 → 正人 → 专修 → 道家之见 | 待法师确认后固定 |
| 专修佛家 | 正见 → 正人 → 专修 → 佛家之见 | 待法师确认后固定 |
| 选修国家 | 正见 → 正人 → 选修 → 国家主流思想 | 待法师确认后固定 |
| 选修儒家 | 正见 → 正人 → 选修 → 儒家之见 | 待法师确认后固定 |
| 选修道家 | 正见 → 正人 → 选修 → 道家之见 | 待法师确认后固定 |
| 选修佛家 | 正见 → 正人 → 选修 → 佛家之见 | 待法师确认后固定 |

**配套正人内容从导图中整理**：诵、拜、念、忏、自检（习）。诵下面的经文与开示、礼拜普贤十愿十万拜、六念自检、忏悔发愿文、家训自检，以及蒙正养德、趋吉避凶、生命觉醒、习劳等均保留。

先列出这8门各应包含哪些正人内容，让法师确认；不预先假定每门都包含全部五项，也不按文件继续拆成法师必须逐项选择的小课。

### 2.3 正愿课：2门

| 课程 | 正见内容 | 对应正愿内容 |

| 菩萨行 | 菩萨行讲解资料 | 具体配套待法师确认后固定 |

正愿行门完整保留：定课自检、菩提心自检、菩提心戒自检、沙弥十戒自检、菩萨戒忏悔与自检（含菩萨戒自检、瑜伽菩萨戒的悔犯）。不能仅凭名称给两门课程自动分配戒律内容，也不能把全部戒律默认开放给每位学员。

| 闭关念佛 | 闭关念佛讲解资料 | 待法师确认后固定 |
| 定时念佛 | 定时念佛讲解资料 | 待法师确认后固定 |
| 临终开示 | 临终开示资料 | 待法师确认后固定 |

念佛等持续实践仍可由法师与学习课程同时安排，不要求结束讲解课程才开始实践。

## 3. 导读与法师安排

### 3.1 导读单独保留

| 内容 | 处理 |
|---|---|
| 导读资料：回归“人间净土”、体系导读、修学导图、平板使用帮助、雨花长老开示、觉光普明、觉醒教育专访 | 公共开放 |
| 皈依、早晚定课、入门自检 | 保留原导图位置，配套范围确认后使用，不计入四类24门 |

### 3.2 先确认课程，再给学员安排

```text
课程设计阶段
整理24门 → 列出每门正见与行门内容 → 法师确认 → 固定课程配置

日常安排阶段
选学员 → 选一门或多门课程 → 填指导与要求 → 发布
```

- 打开一门课程，同时开放其已确认的正见资料和行门内容；课程内部展示闻思修入口，不改变导图归属。
- 专项自检的必填规则写在固定课程配置中，法师日常不需要逐张勾选。
- 课程中的资料、专项自检和实践各有进度；学员提交后，法师查看资料进度、自检分数和答案、心得及实践记录，再确认本课完成。
- 法师可浏览全部资料；学员只能进入公共导读与法师已开放的内容，未安排课程保持锁定。

## 4. 自检设计：课程专项自检与个人自检定课

两种方式共用经确认的自检表，自检和心得体会都归“思”。

| 方式 | 谁决定 | 要求与记录 |
|---|---|---|
| 课程专项自检 | 随开放课程的固定配置带出 | 必须填写，属于本课要求；不能由个人定课设置取消 |
| 个人自检定课 | 学员在已开放内容中自行选择 | 按自身修学情况反复做，可定时，也可随时做 |

### 4.1 个人如何设置

```text
我的自检定课

可选择内容（只显示已开放项）
□ 正信定课自检
□ 正愿定课自检
□ 正行定课自检
□ 已开放的课程专项自检

时间：○ 睡前  ○ 自定时间  ○ 不固定

                [保存]
```

- 正信、正愿、正行的“定课自检”保留各自的导图位置；具体使用哪些表单需确认，不因名称相同就合并。
- 法师未开放因缘果课程时，学员不能选择因缘果自检作为定课；日常入口不增加权限。
- 学员可以在已开放范围内调整自己的自检定课，不需要法师每天重新布置；是否保留已学课程自检的长期使用权限，随复习权限规则确认。
- 自检可随时做，睡前只是原文推荐的时间，不设全体统一提交时刻，也不要求每天填全部表。

### 4.2 填写、回向与记录

```text
选择已开放自检 → 填写 → 回向 → 完成本次 → 查看记录／以后继续
```

- 每次自检最后有回向，文本采用经法师确认的课程内容。
- 一次填写只保存一份记录；如同时满足本课专项自检要求，可在课程与日常记录中同时显示，不重复填写或统计。
- 日常自检完成一次就记录一次，不等于课程整体完成，也不需要法师逐次审批才能再做。
- 持续的自检定课不因某门课结课自动停止；法师仍可查看记录并给予指导，权限按已确认规则执行。

书中“自检课也可作为定课”是一种持续修学方式，不只指 APP 中某一张名为“定课自检”的表。

## 5. 待法师确认的内容

1. 正人8门各包含哪些诵、拜、念、忏、自检内容。
2. 正愿2门、正行7门各自的固定行门配套，哪些共用、哪些专属。
3. 正信“人间净土自检”具体表单，以及十信、八关斋戒自检随哪些课程开放。
4. 正信、正愿、正行的定课自检具体表单与使用范围；是否有共用部分。
5. 正人六念与真机“九次十念”的资料对应；真机缺失或占位的内容另行核对，不改变课程结构。
6. 各门专项自检及持续实践的完成要求，同次自检计入课程要求的条件。
7. 已完成课程及其自检是否长期开放，供复习和个人自检定课使用。
